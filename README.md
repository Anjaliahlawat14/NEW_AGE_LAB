# New Age Programming Languages Lab

This repository contains practical implementations and lab work completed as part of the **New Age Programming Languages** course.

The practicals focus on learning Go programming concepts through simple programs and hands-on experiments.

| 3 | Collections – Slices and Maps | `Exp3_Collections` |
| 4 | Structures and Methods | `Exp4_Person` |
| 5 | Pointers and Memory Concepts | `Exp5_Pointers` |
| 6 | Goroutines and Channels | `Exp6_Goroutines` |
| 7 | Error Handling and Testing | `Exp7_ErrorTesting` |
